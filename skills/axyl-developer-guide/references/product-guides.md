## How To Use Missing URLs

When a `Product guide URL` is missing, not yet defined, or does not contain the expected content, use the Axyl guide root and official-site search or navigation to find the relevant page. When searching by directory, limit the search scope to pages under `https://developers.hiveplatform.ai/axyl/`. Use only results whose URLs retain the `/axyl/` path.

Do not substitute older Hive Developers pages or unrelated Hive SDK guides unless the Axyl documentation explicitly links to them for the exact feature being implemented.
